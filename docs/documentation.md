# Geometric lib

Библиотека на языке Python для вычисления площади и периметра квадрата и треугольника. 
---

## 1. Описание решения
Данный проект умеет считать площадь и периметр квадрата и треугольника.
В зависимости от входных данных рассчитывает по формулам площадь и периметр.
Библиотека поддерживает работу со следующими фигурами:
- **Прямоугольник** (`rectangle.py`)
- **Треугольник** (`triangle.py`)

Каждый файл содержит независимые функции для вычисления площади и периметра соответствующей фигуры.

---
## 2. Описание функций и примеры вызова

### 2.1. Прямоугольник (`rectangle.py`)

#### `area(a, b)`
Вычисляет площадь прямоугольника по двум смежным сторонам.
* **Математическая формула:** $S = a \cdot b$
* **Параметры:**
  * `a` (*int / float*): Длина первой стороны.
  * `b` (*int / float*): Длина второй стороны.
* **Возвращаемое значение:**
  * `int / float`: Площадь прямоугольника.
* **Пример вызова:**
```python
import rectangle

res = rectangle.area(6, 4)
print(res)  # Вывод: 24
```

#### `perimeter(a, b)`
Вычисляет периметр прямоугольника по двум сторонам.
* **Математическая формула:** $P = 2(a + b)$
* **Параметры:**
  * `a` (*int / float*): Длина первой стороны.
  * `b` (*int / float*): Длина второй стороны.
* **Возвращаемое значение:**
  * `int / float`: Периметр прямоугольника.
* **Пример вызова:**
```python
import rectangle

res = rectangle.perimeter(3, 4)
print(res)  # Выведет: 14
```

---

### 2.2. Треугольник (`triangle.py`)

#### `area(a, h)`
Вычисляет площадь треугольника по основанию и высоте.
* **Математическая формула:** $S = \frac{a \cdot h}{2}$
* **Параметры:**
  * `a` (*int / float*): Длина стороны основания.
  * `h` (*int / float*): Высота, опущенная на основание $a$.
* **Возвращаемое значение:**
  * `float`: Площадь треугольника.
* **Пример вызова:**
```python
import triangle

res = triangle.area(6, 4)
print(res)  # Выведет: 12.0
```

#### `perimeter(a, b, c)`
Вычисляет периметр треугольника по трем его сторонам.
* **Математическая формула:** $P = a + b + c$
* **Параметры:**
  * `a` (*int / float*): Длина первой стороны.
  * `b` (*int / float*): Длина второй стороны.
  * `c` (*int / float*): Длина третьей стороны.
* **Возвращаемое значение:**
  * `int / float`: Периметр треугольника.
* **Пример вызова:**
```python
import triangle

res = triangle.perimeter(3, 4, 5)
print(res)  # Выведет: 12
```
